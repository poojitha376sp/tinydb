# ADR-015: Read the Agent's Action Robustly, in Code (new)

## Status

Accepted.

## Context

mini-swe-agent takes one shell command per step from a fenced block in the model's text. The free models broke this in ways the original design did not foresee:

- The library's pattern matched from the first opening fence to the last closing fence, so a reply with two blocks became one broken command. Writing a file with a heredoc that itself contained a fence closed the block early (PR #12 review).
- `gpt-oss` sometimes put its command only in its reasoning field and left the reply text empty. After three such replies in a row the library stopped the run (PR #12 review).
- Agents wrote Python with `python3 -c "..."`, where bash ran the backticks inside docstrings as commands and silently corrupted files.
- The Reviewer and the Analyst sometimes tried to finish at step 1 without writing their output file (PR #15 review).

## Decision

All of this is handled in the harness code, not by asking the model nicely:

- `split_actions` finds blocks and treats a fence inside an open heredoc as file content, not as the end of the command. Exactly one block per reply is accepted; anything else gets a short format error that explains the rule.
- If the reply text has no block but the reasoning field has exactly one, that block is used, and the run counts it (`recovered_from_reasoning`).
- Up to 5 format errors in a row are allowed (the library default is 3).
- The system prompt tells every agent to write files with a quoted heredoc (`cat > FILE <<'EOF'`), and the guard explains this when it blocks a backtick.
- An agent cannot finish until its required output file exists (`spec.md`, `design.md`, the test file, `review.json`). Each refused finish is counted (`early_submits`).

## Consequences

- Good: the same free models now complete their stages in almost every run; one E1 review (S2, trial 2) still stopped after 5 format errors in a row. Every stage records how often each fix was needed, so the report can show how much the harness, not the model, contributed.
- Bad: the harness now contains parsing rules that must be kept in step with the library's own parser; self-tests cover each case (heredoc with fences, two blocks, empty reply).
