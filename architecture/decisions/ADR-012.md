# ADR-012: Fallback Chains per Role, Reviewer on NVIDIA's Free API (supersedes ADR-006)

## Status

Accepted. Supersedes ADR-006.

## Context

ADR-006 chose Gemini Flash for the three build roles and GitHub Models (Groq as fallback) for the Reviewer, all on free tiers. Each part failed in real runs:

- Gemini 2.5 Flash was closed to new keys. The free Flash Lite models allow about 15 requests a minute and 500 a day each, and a busy model returned `RateLimitError` in most runs (all 8 E2 runs switched model at least once).
- GitHub Models answered every request on this account with a bare `OK` (HTTP 200), so no review could run (PR #7, run 44777819084). Groq had retired `llama-3.3-70b`.
- Groq's `gpt-oss-120b` then worked, but its free tier allows 8000 tokens a minute and 200K a day. The daily quota ran out halfway through experiment E1 (pilot runs in `results/runs.md`).
- Cerebras requires a payment method, which the zero budget rules out. NVIDIA's free API had retired `gpt-oss-120b` (3 Sep 2026) and `gpt-oss-20b` (18 Nov 2026).

## Decision

- Each role has an ordered fallback chain (`config.py`, overridable with the repository variables `AUTOSE_BUILD_MODELS` and `AUTOSE_REVIEW_MODELS`). A model that is busy hands the request to the next one. A model whose daily quota is used up is dropped for the rest of the run.
- Build roles: Google models only, starting with `gemini-3.5-flash-lite` and `gemini-3.1-flash-lite`, ending with `gemma-4-31b-it`.
- Reviewer: NVIDIA's free API (build.nvidia.com), `nvidia/nemotron-3-ultra-550b-a55b` first, then `mistralai/mistral-large-4-1t-a52b`, `minimaxai/minimax-m3.1-flash`, and Groq `gpt-oss-120b` last. A probe of all 13 free NVIDIA chat models chose these on speed and on following the one-command action format. No Google model is allowed in this chain; a self-test checks that.
- Models with small free limits get a per-request context budget (`CONTEXT_BUDGET`): the system prompt and the task are kept, plus as many recent steps as fit. Output is capped at 2500 tokens for those models.

## Consequences

- Good: the cost stayed at zero, and the Builder and the Reviewer are still from different model families (Google against NVIDIA, Mistral, MiniMax and OpenAI).
- Good: a busy model now costs a switch, not a run. An early run with a single model (I1, run 44692766501) stopped in Stage 1 on a 503 "high demand" error; later runs record the switches per stage in `stage_results.json` instead.
- Bad: the Reviewer model changed twice during the work (Groq gpt-oss, then Nemotron). E1 results are only compared within one model; the Groq runs are reported as a pilot.
- Bad: free model lists change without notice (two retirements in this project alone). The chain makes this survivable, but the results depend on which models were alive on the day.
